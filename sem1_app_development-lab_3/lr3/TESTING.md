# Быстрый запуск тестов

## Активация виртуального окружения и запуск

```powershell
# Перейти в директорию проекта
cd lr3

# Активировать виртуальное окружение
.\venv\Scripts\Activate.ps1

# Запустить все тесты
pytest tests/ -v

# Запустить тесты для конкретного модуля
pytest tests/test_user_repository.py -v
pytest tests/test_product_repository.py -v
pytest tests/test_order_repository.py -v
```

## Что тестируется

✅ **Пользователи (5 тестов):**
- Создание пользователя
- Поиск по email
- Обновление данных
- Удаление
- Получение списка всех пользователей

✅ **Продукты (5 тестов):**
- Создание продукта
- Получение по ID
- Обновление остатков на складе (quantity_in_stock)
- Получение списка всех продуктов
- Удаление

✅ **Заказы (6 тестов):**
- Создание заказа с несколькими продуктами
- Получение заказа по ID
- Получение списка всех заказов
- Добавление продукта к заказу
- Удаление продукта из заказа
- Удаление заказа
